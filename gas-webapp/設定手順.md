# GAS Web管理画面 設定手順

このフォルダは、福岡トヨペットの担当者がURLを開くだけで中古車カードを更新するためのWeb管理画面です。

## 1. Apps Scriptを作る

1. https://script.google.com/ を開く
2. 「新しいプロジェクト」
3. プロジェクト名を `福岡トヨペット 中古車カード管理` にする
4. 最初からある `コード.gs` の中身を削除し、このフォルダの `Code.gs` を全部貼る
5. 左の「＋」→「HTML」→ ファイル名を `index` にして、このフォルダの `index.html` を全部貼る
6. 左の「プロジェクトの設定」→「マニフェスト ファイルをエディタで表示する」をオン
7. `appsscript.json` を、このフォルダの `appsscript.json` の内容に置き換える

## 2. 秘密情報を設定する

「プロジェクトの設定」→「スクリプト プロパティ」に次を登録します。

| プロパティ | 値 |
|---|---|
| `GH_TOKEN` | GitHubのFine-grained token |
| `EDITOR_KEY` | 管理画面へ入るための20文字以上のランダムな編集用キー |
| `GH_OWNER` | `shin-adsheet`（省略可） |
| `GH_REPO` | `fukuoka-toyopet-ucar`（省略可） |
| `GH_BRANCH` | `main`（省略可） |

`GH_TOKEN` はブラウザには送信されません。

Fine-grained tokenは対象リポジトリを `fukuoka-toyopet-ucar` だけに限定し、Repository permissionsを次のようにします。

- Contents: Read and write
- Actions: Read and write（管理画面の「Gazooを今すぐ更新」を使う場合のみ）

## 3. Webアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」
3. 「次のユーザーとして実行」：**自分**
4. 「アクセスできるユーザー」：**全員**
5. 「デプロイ」
6. 初回だけGoogleの権限確認を行う
7. 発行された `/exec` のURLをブックマークする

Googleの個人情報権限は要求しません。管理画面を開いた後、`EDITOR_KEY` と一致する編集用キーが必要です。すべての保存・公開・画像更新・Gazoo実行でサーバー側が再照合します。

## 4. 普段の使い方

1. Web管理画面のURLを開く
2. 管理パスワード（`EDITOR_KEY`）を入力する
3. クルマを追加・編集する、または「Excelファイルを選ぶ」で支給された特選車Excelを読み込む
4. Excelの場合は取込内容と掲載ページを確認する
5. 確定したら青い「変更をサイトへ反映」を押す

入力内容は共有下書きへ自動保存されます。公開時はGazoo自動更新も続けて開始するので、通常は上記の青いボタンだけ使えば完了です。

### クルマを1台ずつ追加する

「＋ 新しいクルマを追加」を押すと、最初に追加のしかたを選びます。

1. **GazooのURLから取り込む**（おすすめ）
   - URL欄にGazooの車両詳細URLを貼ると、その場で読み込みが始まります
   - 店舗・車名・掲載番号・価格・年式・走行距離・装備・写真が自動で入ります
   - 読み込んだ内容（写真つき）を確認してから「このクルマを追加」を押します
   - **複数のURLを改行で区切って貼れば、まとめて追加できます**
   - 読み込めなかったURLは理由が表示され、成功した分だけ追加されます
2. **手動で入力する**
   - Gazooに載っていないクルマ向け。すべて自分で入力します

追加したあとに編集画面でURLを貼り直した場合も、貼った時点ですぐ読み込みます。

### 一覧まわりの操作

- クルマをドラッグすると、掲載する並び順を変えられます（挿入位置が青い線で表示されます）
- 車名や支払総額が空のクルマには「要入力」が付きます
- 似た内容のクルマは「このクルマを複製」で増やせます

### 完成プレビューとCMSコード

画面下部に、選択中ページの全カードが表示されます。

- 「PC」：2列の完成イメージ
- 「スマホ」：1列の完成イメージ
- 「コードをコピー」：選択中のページIDとGitHub接続先が入ったCMSコードをコピー

CMSへ貼るコードはページごとに最初の1回だけ必要です。その後の車両変更は「変更をサイトへ反映」だけで更新されます。

### 特選車Excelの取込

- 対応形式：福岡トヨペット支給の `.xlsx`
- 読み込む項目：車両番号、店舗、車名、車台番号下3桁、価格、年式、走行距離、車検、燃料、ミッション、色、オプション、Gazoo URL
- 取込前に台数・車名・店舗・価格を確認できます
- 今のページとの入れ替え、または新規ページ作成を選べます
- 同じ車両番号は既存車を更新し、高画質画像を引き継ぎます
- Google DriveへExcelを保存しないため、Driveの追加権限は不要です
- 店舗名は「久留米I」のような略記を「久留米インター店」へ自動で直します。一覧にない店舗名が出た場合は警告が出ます
- 支払総額がExcelに入っていない場合は空欄のままにし、掲載開始後にGazooから取り込みます

### 販売開始前の取り込み（掲載待ち）

販売開始前のGazoo URLを開くと「すでに売約済みとなっております」の画面になり、車両情報を取れません。
そのため取り込みは次のように動きます。

1. Excelから取り込んだ車は、まず**手動管理（掲載待ち）**として登録されます
2. Excelの内容（店舗・車名・車両価格・年式・走行距離・装備など）がそのまま表示されます
3. GitHub Actionsが定期的にGazooを見に行き、**掲載が始まった時点で自動更新へ切り替え**、支払総額・写真・装備を最新にします
4. 切り替わると一覧の「掲載待ち」表示が消え、「自動」になります

掲載待ちの間は、売約済みにはなりません。掲載開始を待っているだけです。
先に手で内容を直したい場合は、そのまま編集できます。

### Gazoo自動 / 手動

各車に「Gazoo更新モード」があります。

- **自動更新**：Gazoo詳細URLを貼ると店舗・車名・掲載番号・価格・車両情報・高画質画像をすぐ自動入力。その後はGitHub Actionsが定期更新
- **手動管理**：その車はGazoo自動巡回の更新対象から外す
- **掲載待ち**：Excel取込直後の状態。手動管理だが、掲載開始を検知すると自動更新へ切り替わる（モードを自分で選び直すと、この自動切り替えは止まります）

自動更新中は、Gazooから同期する欄を編集できません。手入力したい場合は「手動管理」へ切り替えます。画像だけ手動で維持したい場合は「画像もGazooから自動更新」をオフにしてください。車両No.はGazooから取得できないため、自動更新中でも手入力できます。

「Gazooを今すぐ更新」はGitHub Actionsをその場で開始します。完了には通常少し時間がかかるため、1〜2分後に「公開データを再読込」で結果を確認してください。

定期更新では次のように動きます。

- 写真はGazooの高画質版（`_L`）を優先し、無ければ中・小の順に取得します
- 支払総額が車両価格を下回るなど読み違いが疑われる場合は、価格を更新しません
- 売約済みにした車も14日間は念のため見に行き、Gazooの掲載が戻っていれば売約表示を解除します

## セキュリティ上の注意

- `GH_TOKEN` をHTML、メール、CMSコードへ貼らない
- GASプロジェクトの編集権限を不要な人へ渡さない
- `EDITOR_KEY` は20文字以上の推測されにくいランダム文字列にし、他サービスのパスワードを流用しない
- WebアプリURLと編集用キーを同じ公開ページへ掲載しない
- 共有PCでは「この端末に編集用キーを保存する」をオフにする
- 担当変更・紛失時は `EDITOR_KEY` を変更すると、保存済みの全端末をログアウトできる
- GitHub tokenはこの1リポジトリだけに限定する
